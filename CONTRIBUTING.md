# Contributing to IXV-LM

[English](./CONTRIBUTING.md) | [日本語](./CONTRIBUTING_ja.md)

This document describes guidelines for contributing to the project.

## Contribution License and Provenance

By submitting a contribution, you agree that it is licensed under the repository's [MIT License](./LICENSE) and
confirm that you have the right to submit it. Preserve applicable copyright and license notices.

Disclose copied or substantially adapted third-party material in the pull request, including its source URL, version
or commit, and license. Update [PROVENANCE.md](./PROVENANCE.md) and [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)
when applicable.

## Training Data

- Do not commit training data, token files or checkpoints. They live outside the repository (`.gitignore` excludes
  them).
- A new data source is added to the [ledger](corpus/ledger.toml) first, with its URL, version, license and filters.
  Elvez approves it before it is used.
- **Do not add text generated by Claude** to training data (see "Data policy" in the README). Documents written by
  Claude in this repository carry a note saying so.

## How records are written

Records in this repository (README, experiment notes, the ledger, comments) follow these lines (decided 2026-11-25):

- Decisions are written with the date and the conclusion only, without the names of the people who made them.
- Machines are named by model (such as "M3 Ultra") or as "the training machine", not by internal names. Process IDs
  are not written.
- Paths inside unpublished products or repositories, unpublished links, local paths and legal reviews are not written.
- The rights holders and authors of Elvez's own works are written in the ledger as facts.

## How to Contribute

### Reporting Bugs

Create an Issue with:

- A clear and descriptive title
- Steps to reproduce the problem
- Expected behavior and actual behavior
- For the input method: the reading you typed, what came out, and what you wanted
- Mac model and memory, macOS version, Python version

### Feature Requests

Create an Issue with a clear title, a description of the feature, and its use cases.

### Pull Requests

1. Create a branch from `main` (format: `username/YYYYMMDD-description`)
   ```bash
   git checkout -b user/20261124-fix-feature
   ```
2. Follow the style of the existing code. Comments and documents are written in Japanese.
3. Record experiments in `experiments/YYYYMMDD-name/README.md`: settings, commands, results, and what was not tested.
4. Do not run GPU work on top of a running training job (see "Running on the training machine" in the README).
5. Update README.md / README_ja.md for user-facing changes, and add an entry under `[Unreleased]` in
   [CHANGELOG.md](CHANGELOG.md) / [CHANGELOG_ja.md](CHANGELOG_ja.md).

## Questions

Ask in [Issues](https://github.com/elvezjp/ixv-lm/issues) or at info@elvez.co.jp.
