# 2026-11-07 日本語 Wikipedia 全量の学習（KDA ハイブリッド 0.1B、M3 Ultra）

> **注意:** この学習には、チャンク内の逆行列の桁落ちのバグが入っていた（[記録](../20261107-bf16-speed/README.md)）。`ckpt-43000` では誤差が小さく、修正後のコードでも検証損失は 2.7736 のままだった。学習の序盤にどこまで影響したかは分かっていない。

## 目的

M3 Ultra で、手書きの Metal カーネルを使い、0.1B のモデルに日本語 Wikipedia を1周ぶん学習させる。最後まで回し切り、学習率の減衰の効果と生成の質を見る。

**最後まで回した。** 43,000 ステップで完了した。途中で GPU のロックアップが2回起き、どちらも自動で再開した。

## 条件

| 項目 | 内容 |
|---|---|
| マシン | Apple M3 Ultra、メモリ 512GB（Mac Studio） |
| データ | [wikimedia/wikipedia](https://huggingface.co/datasets/wikimedia/wikipedia) `20231101.ja`。1,389,467 文書、1,409,239,222 トークン |
| トークン | 語彙 16,384 の byte-level BPE。4.857 バイト/トークン。末尾の 200万トークンが検証 |
| モデル | KDA ハイブリッド（KDA 3：全注意 1）、99,486,636 パラメータ、12層、d=768、12ヘッド、NoPE |
| 学習 | バッチ 16 × 2,048 トークン、AdamW、学習率 6e-4、ウォームアップ 1,000、末尾20%で減衰 |
| カーネル | `KDA_METAL=1`（手書きの Metal カーネル） |
| 読み方 | 位置は無作為の復元抽出。読んだトークン数は全量と同じ約14億だが、全文書を1回ずつ読むわけではない |
| 検証 | 1,000 ステップごと、32 バッチ（約105万トークン） |
| 保存 | 500 ステップごと |

3,000 ステップまでは別の実行で、`ckpt-3000` から再開した。下の速度などの値は 3,000 ステップ以降の記録である。

学習率が一定の区間では、30,000 から 34,000 ステップで 0.014 しか下がらなかった。減衰は 34,400 ステップから始まり、34,000 ステップの値から最後までに 0.236 下がった。

[Mac mini の 10M](../20261106-wiki-full-kda/README.md) の検証損失は 4.588 だった。モデルの大きさ、文脈の長さ、検証の範囲、減衰の有無がすべて違うので、この差を1つの要因の効果としては読めない。

## 生成の例

`ckpt-43000`、温度 0.7、種 0、80 トークン。太字がプロンプト。抜粋。

> **日本の首都は**東京。京都は京都の京都と呼ばれていたが、本項では京都の京都について記述する。

> **織田信長は**美濃の国衆と地頭らに上下に上下二列に並んだ騎馬隊を率いて、美濃府中を警固して諏訪氏・土岐氏・織田氏らと合流した。

> **東京都は、**合計4万から5万点以上の利用となり、最大利用者数は約6万人と推定されている。

> **人工知能とは、**仮想空間の実現という概念を共有し、仮想空間の実現は相互接続やマルチメディアの実現といった概念を共有している。

> **夏目漱石は**夏目漱石の詩「死者のための詩」に感銘を受けた。

> **ソフトウェア開発において、**ソフトウェア開発者がソフトウェアを使用することを「ソフトウェア開発」という。

文はつながり、話題に沿った語彙も出る。10M のように同じ語だけが並ぶ出力はこの6例にはなかったが、「京都の京都」「ソフトウェア開発者」のような語の繰り返しは残る。事実も合わない。6例を見ただけで、率は測っていない。

## 運用の記録

| 時刻 | 出来事 |
|---|---|
| 11/06 21:35 | `ckpt-3000` から再開 |
| 11/07 03:46 | GPU のロックアップ。`ckpt-13500` から自動で再開 |
| 11/07 06:39 | GPU のロックアップ。06:40 に `ckpt-18000` から自動で再開 |
| 11/07 21:19 | 43,000 ステップで完了 |

06:40 以降の約14.6時間は、ロックアップが起きなかった。学習と並行して、データの取得を動かしていた。

## 分かったこと

- M3 Ultra で、手書きの Metal カーネルを使って 0.1B を最後まで回せた。
- 500 ステップごとの保存と自動の再開で、ロックアップがあっても完走できた。
- 学習率の減衰の効果が大きい。

## 決めたこと

- 構造は KDA ハイブリッドで進める（2026-11-07 決定）。同じ条件の Transformer との比較は回していない。

## 分からないこと

- ロックアップの原因。手書きカーネルが原因かどうかは確定していない。
- 2,048 トークンより長い文脈での性能。
- 種を変えたときの揺れ。
